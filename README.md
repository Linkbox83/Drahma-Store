# Drahma Store

A responsive, static storefront concept for Drahma Store.

## Included

- Women, Men, Accessories, Best sellers, About, Store policy, and shopping bag navigation
- The eight product concepts from the Drahma Store alpaca catalog
- A responsive collection layout and local shopping bag preview
- An original Drahma Store mountain wordmark drawn in the page SVG
- No payment processing or checkout; the storefront is a preview while product details are being confirmed

## Preview

Open `index.html` in a browser, or publish this repository with GitHub Pages by selecting the `main` branch and `/(root)` in the repository's Pages settings.
